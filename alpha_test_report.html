🚨 Logged Alpha Defects (4 Issues Open for Fixes)

[DEFECT-01] TC-A025: Hierarchical Date Inversion in Project Tasks

Severity: Medium | Module: ProjectTask & ProjectController

Root Cause: FormRequest only checked due_date >= start_date, omitting check against parent Project->start_date.

Fix: Add 'start_date' => 'date|after_or_equal:project_start_date' rule in TaskRequest.

[DEFECT-02] TC-A044: Strict Image MIME Type Validation Blocks Camera Uploads

Severity: Low | Module: Payment Receipt Upload Pipeline

Root Cause: Rule 'receipt_file' => 'mimes:jpg,jpeg,png,pdf' rejected mobile camera .jfif format.

Fix: Expand MIME types to include 'mimes:jpg,jpeg,png,pdf,jfif,webp'.

[DEFECT-03] TC-A062: Fractional Decimal Quantities on Discrete Material Items

Severity: Medium | Module: InventoryController & ProjectMaterial Allocation

Root Cause: Allocation endpoint allowed floating points on discrete unit items (pcs, sets).

Fix: Add rule: if (in_array($unit, ['pcs', 'sets'])) validate 'integer'.

[DEFECT-04] TC-A079: Zero-Quantity Inter-Project Transfer Voucher Creation

Severity: Low | Module: RoofingTransferController & ProjectMaterialTransfer

Root Cause: Transfer controller evaluated if ($qty < 0) instead of if ($qty <= 0).

Fix: Update rule to 'quantity_transferred' => 'numeric|gt:0'.
